Hướng Dẫn Cài Đặt ActionLock Free (APK & PWA)

Cách 1: Cài đặt trực tiếp làm App trên Điện thoại (10 giây — Không cần máy tính)

• Trên Android (Chrome): Mở file ứng dụng này trên Chrome ➔ Nhấn biểu tượng ⋮ (3 chấm) ở góc phải ➔ Chọn "Thêm vào màn hình chính" (Add to Home screen / Install App) để chạy toàn màn hình với Camera AI đếm nhịp thật.

• Trên iPhone/iPad (Safari): Nhấn nút Chia sẻ (Share) ➔ Chọn "Thêm vào Màn hình chính" (Add to Home Screen).

Làm sao để biến gói mã nguồn thành 1 file .APK tải về điện thoại? (Không cần biết lập trình)

Vì lý do bảo mật, trình duyệt không tự sinh file nhị phân .apk trực tiếp, nhưng tôi đã đóng gói sẵn cỗ máy tự động đóng gói APK miễn phí trên GitHub trong file actionlock_android_source.zip. Bạn chỉ cần làm đúng 4 thao tác sau (mất 2 phút):

  1. Bước 1: Tải file actionlock_android_source.zip ở khung chat về máy và Giải nén (Unzip) ra 1 thư mục.
  2. Bước 2: Vào trang github.com/new (đăng nhập tài khoản GitHub miễn phí), đặt tên bất kỳ (ví dụ: actionlock-apk) rồi bấm Create repository.
  3. Bước 3: Nhấn dòng chữ "uploading an existing file", kéo toàn bộ các file/thư mục vừa giải nén thả vào đó rồi bấm nút xanh Commit changes.
  4. Bước 4: Nhấn vào tab Actions ở thanh menu trên cùng của GitHub ➔ Đợi khoảng 90 giây cho tích xanh hiện lên ➔ Bấm vào dòng kết quả và tải file ActionLock-Free-v1.0-debug.apk về điện thoại cài đặt!
Sau khi cài file .APK vào điện thoại, làm sao để nó khóa các App khác ổn định?

Ngay khi mở app ActionLock Free vừa cài từ file APK:

  • Bấm nút "1. Mở Cài Đặt Trợ Năng" ➔ Bật công tắc cho ActionLock Free Blocker.
  • Bấm nút "2. Mở Quyền Hiển Thị Trên App Khác" và "3. Bỏ Tối Ưu Hóa Pin".
  • Từ lúc đó, dịch vụ ngầm KeepAliveForegroundService và AppBlockerAccessibilityService sẽ canh gác 24/7: hễ bạn bấm mở TikTok, Instagram, YouTube, Facebook hay Game khi chưa tập hoặc khi hết giờ đếm ngược, hệ thống lập tức chặn màn hình đó lại và bắt bạn hoàn thành đủ nhịp Hít đất / Squat mới cho vào!
Chi tiết kỹ thuật trong gói mã nguồn (Dành cho máy tính có Android Studio)

Gói dự án Android Studio hoàn chỉnh (actionlock_android_source.zip) đã được tạo kèm theo với đầy đủ:

  • AppBlockerService.kt: Dịch vụ AccessibilityService chặn trực tiếp TikTok, Instagram, YouTube, Facebook ở cấp hệ điều hành Android.
  • PoseRepDetector.kt: Nhận diện khớp xương bằng Google ML Kit Pose Detection trên thiết bị.
  • .github/workflows/build-apk.yml: Tải lên GitHub để tự động xuất file ActionLock-Free-debug.apk miễn phí trên đám mây hoặc chạy lệnh ./gradlew assembleDebug trong Android Studio.
